# LinkedIn Post — Portfolio Edwin Tovar

🚀 **Acabo de construir mi portafolio profesional con Next.js 16 + TypeScript + IA** — y quiero compartir cómo lo hice.

Hace unas semanas me propuse crear un portafolio que no solo mostrará mi experiencia como QA Engineer, sino que también demostrara mis habilidades técnicas en automation, CI/CD y testing E2E.

El resultado:

✅ **Landing page SPA** con 7 componentes (Hero, About, Experience, Projects, Contact, Footer, Header)
✅ **Bilingüe ES/EN** con React Context (sin librerías externas)
✅ **Selector de tema**: Claro 🌞 / Oscuro 🌙 / Sistema 💻 (persistido en localStorage)
✅ **37 tests E2E automatizados** con Playwright + Page Object Model
✅ **14 casos de prueba manuales** documentados
✅ **CI/CD** con GitHub Actions (lint → build → deploy a GitHub Pages)
✅ **CV en PDF** generado automáticamente en ambos idiomas
✅ **Exportación de casos de prueba** a Excel para reportes

Tech stack: Next.js 16 | TypeScript | Tailwind CSS v4 | Playwright | GitHub Actions

📸 Podés verlo en vivo: https://etovara.github.io/portfolio
🔗 Repo: https://github.com/etovara/portfolio

Lo más interesante? Todo el proyecto fue desarrollado con asistencia de IA (Claude/Copilot), lo que demuestra cómo podemos potenciar nuestro trabajo combinando experiencia técnica con herramientas de IA generativa.
