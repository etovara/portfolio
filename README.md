# 🚀 SDET Portfolio & Testing Lab — Edwin Tovar

Este no es solo un portafolio profesional; es un **Laboratorio de Ingeniería de Calidad Abierto**. Diseñado para demostrar el potencial de un **QA modernizado por IA** y servir como recurso para la comunidad de testers.

## 🎯 Propósito del Proyecto
1. **Showcase para Reclutadores:** Acceso rápido a mi trayectoria, habilidades y, sobre todo, a mi **capacidad de construir infraestructura de calidad**.
2. **Laboratorio de Comunidad:** Un espacio donde otros testers pueden clonar, ejecutar y proponer mejoras a las suites de automatización.
3. **Sinergia QA + IA:** Demostración real de cómo integrar LLMs en el ciclo de vida del testing para análisis y auditoría.

## 🛠️ Stack de Ingeniería
- **Frontend:** Next.js 16 + TypeScript + Tailwind CSS v4.
- **Testing Core:** Playwright (Visual Regression + Data-Driven Testing).
- **AI Audit:** Motor de auditoría cualitativa con Gemini SDK.
- **CI/CD:** Pipeline profesional en GitHub Actions.

## 🧪 Áreas de Testing (¡Explóralas!)

### ⚙️ Automation Engine
Ubicado en `testing/automation/specs/engine.spec.ts`. Utiliza **DDT (Data-Driven Testing)** para validar que la UI coincida con el `data.json`. ¡Clónalo y añade tus propios casos!

### 👁️ Regresión Visual
Validación pixel-perfect en múltiples viewports para asegurar que el diseño sea resiliente a cambios de código.

### ♿ Accesibilidad (a11y)
Integración con **axe-core** para certificar el cumplimiento de WCAG 2.1 AA.

### 🤖 AI Quality Gate
Ejecuta `npm run test:ai-audit` para ver cómo la IA analiza la calidad del sitio, el SEO y el branding profesional de forma autónoma.
