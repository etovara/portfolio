# Edwin Tovar | Portfolio

Portfolio profesional desarrollado con Next.js 16, TypeScript y Tailwind CSS.

## Características

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Internacionalización (ES/EN)
- Modo oscuro

## Ejecución local

```bash
npm install
npm run dev
```

## Construcción para producción

```bash
npm run build
```
