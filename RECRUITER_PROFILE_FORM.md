## 📐 Instrucciones para el Agente IA

Al recibir este formulario completado, debes:

1. **Estructurar los datos** en un JSON con la taxonomía del formulario
2. **Detectar brechas**: campos obligatorios vacíos, inconsistencias (ej: nivel de idioma vs. skills que lo requieren)
3. **Calcular score de perfil** (0-100%) basado en completitud y coherencia
4. **Generar resumen ejecutivo** de 2 párrafos para reclutador
5. **Sugerir roles compatibles** según skills, experiencia e industrias
6. **Recomendar áreas de mejora** (certificaciones faltantes, skills desactualizados)

### Formato de salida esperado

```json
{
  "score_perfil": 85,
  "completitud": { "seccion": "%", "...": "..." },
  "brechas": ["Falta certificación ISTQB", "Sin métricas cuantificables en Experiencia 2"],
  "roles_sugeridos": ["Senior QA Engineer", "QA Lead", "Automation Architect"],
  "resumen_ejecutivo": "Candidato con perfil sólido...",
  "mejoras_recomendadas": ["Obtener AWS Certification", "Agregar métricas a todos los logros"]
}
```
